# THAISERKIT Next.js Documentation

เอกสารชุดนี้อธิบายระบบปัจจุบันในฐานะ **Next.js 16.3.4 application** โดยตรง ไม่มี changelog หรือเอกสารการย้าย framework เก่าอยู่ในชุดส่งมอบ

เอกสารหลัก:

1. `ARCHITECTURE-TH.md` — โครงสร้างระบบและ service boundaries
2. `FEATURES-TH.md` — ฟีเจอร์ทั้งหมดที่อยู่ในระบบ
3. `ERD-TH.md` — relational data model
4. `SYSTEM-FLOWS-TH.md` — auth / checkout / payment / stock / queue / tenant flow
5. `STACK-TH.md` — technology stack
6. `EQUIPMENT-KIT-BUILDER-TH.md` — ระบบจัดเซ็ตอุปกรณ์
7. `ENVIRONMENT-TH.md` — configuration และ secrets
8. `DEPLOYMENT-TH.md` — deploy และ production checks
